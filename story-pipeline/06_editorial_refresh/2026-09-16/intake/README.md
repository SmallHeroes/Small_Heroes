# עותקי קליטה של הסיפורים המאושרים

18 הסיפורים בתיקייה זו שומרים את הטקסט, הכותרות והפרמטרים שאישר גיא.
ההבדל מעותקי העריכה הוא הסרת שני שדות מצב מכותרת הקובץ ותקנון סיומי שורות.
מצב ההכנה והקישור לאישור נשמרים ב־manifest.json ולא בתוך טקסט הסיפור.

הקבצים עברו את בדיקת פורמט הטקסט הקיימת במסלול הפרסום.
זאת אינה בדיקת עריכה ספרותית ואינה פרסום למאגר הפעיל.
הם עדיין ללא הוראות איור חדשות, אישור עורך חיצוני ובדיקה טכנית עצמאית.
אין לייבא אישורי עריכה או הוראות איור מהסיפורים שהוחלפו.
