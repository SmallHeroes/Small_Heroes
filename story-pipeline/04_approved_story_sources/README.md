# Product-Accepted Story Sources

This directory preserves story text that has all of:

1. a closed external Editor PASS;
2. independent artifact-fidelity PASS;
3. explicit Guy product acceptance; and
4. a content-addressed, canonical story document.

Each accepted slot has its own directory containing `story.md`, the exact
`editorial-review.json` and a binding `manifest.json`. Guy acceptance records
remain under `approvals/`.

This is story-text source authority only. It is not the served story bank and
does not authorize Wizard selection, Visual Contract authoring or rendering.
Before a source can replace `story-bank/v3-approved/<companion>_<direction>.md`,
it still needs page-grounded visual directions, Story Source evidence, both
gender personalization passes and the normal import/visual qualification.

Never edit an accepted story in place. A changed story must re-enter Editor,
artifact audit and Guy acceptance as a new version.
