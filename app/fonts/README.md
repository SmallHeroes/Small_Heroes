# Local webfonts

The font files and their individual OFL notices are from the [Google Fonts repository at c30b221](https://github.com/google/fonts/tree/c30b221beb0c1da59d563feb91ec8656a1fa972a/ofl).
Each directory matches its upstream family directory. Variable filenames use `-Variable` in this checkout in place of the bracketed axis list. The font bytes are unchanged. The notices are checked in with normalized line endings and trailing spaces.

The root layout and personal product preview use these files through `next/font/local`. Keep the notices with the assets when redistributing them. Suez One and the separate PDF font pipeline use their existing sources.
