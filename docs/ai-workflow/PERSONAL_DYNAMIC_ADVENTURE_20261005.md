## Requirement and decision

The adventure should offer changing situations, movement, search, encounters,
play or surprises that matter to the next event. These are possibilities rather
than a checklist. Resilience belongs within that adventure. Quiet scenes and
several scenes in one setting can develop through choices, relationships and
play. New scenery alone does not establish development.

Existing instructions already ask for dynamic stories. The diagnosis is an
emphasis/evaluation gap: detailed causal completeness was rewarded while lived
development was insufficiently scrutinized. This is a hypothesis about the
engine, not proof that a prompt caused one outcome. The repeated observation
profile is also a contributing possibility, not a universal engine defect.
