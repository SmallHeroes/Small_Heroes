## Root cause and implemented boundary

Complete source-beat accounting was conflated with action-semantic representability. A visible beat that described static state, lighting, composition focus, a graphic sound cue, or an ambient event had no typed non-action lane and therefore fell into a terminal unsupported classification even when it was already represented by an exact page `mustShow` contract.

The implementation adds the closed `presentation_requirement` coverage disposition. It requires:

- one closed presentation class;
- one exact same-page `/pageContracts/{index}/mustShow/{item}` pointer;
- the exact current string value at that pointer;
- compiler-resolved source evidence;
- explicit preservation through Semantic Reconciliation before Blueprint qualification.

The lane is review evidence, not action authority. It cannot satisfy an `action_requirement`, does not widen `represented_elsewhere`, does not bypass action/spatial validators, and remains `reviewState: unreviewed` until the existing product-review boundary acts.
