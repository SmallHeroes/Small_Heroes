## Corrections discovered during integration

An initial local materialization attempt replaced the historical v3 tree and
therefore broke legacy tests. It was not committed. The entire tracked
`story-bank/v3-approved` tree was restored from HEAD and verified clean before
the technical commit. The final architecture uses an isolated QA bank and an
explicit non-Production flag.

The story `chameleon_koko_adventure` contains the ordinary Hebrew word `איתי`
("with me"). The old denylist treated it as the English legacy name `Itai`.
The general correction removes only the Hebrew word from that denylist, retains
the English name and adds direct strict/warn regressions.

The first complete repository gate also found two stale assertions: the check
script contract did not include the already approved autonomous TypeScript
gate, and a legacy measurement test expected the pre-catalog runner expression.
Only those assertions were updated. Their focused suite passes 12/12.
