## Approved scope

One fictional Neta profile, eight narrative spreads. The author receives the approved profile and companion character, not a GPT outline, manuscript or previous review. A single fresh Claude Code invocation selects between two ideas, builds the whole outline and writes the original manuscript. A second fresh invocation edits only that new manuscript and its approved brief. Both plans and manuscripts remain separate artifacts. The writer and editor use Opus 5.5 with medium effort.

GPT 6 Astra then reviews full prose and the approved profile as a Codex subagent. This is a literary advisory review, not an OpenAI API invoice event, human product acceptance or Claude Code technical PASS. The editor's self assessments are withheld initially. Astra subscription usage is not monetarily measured here.
