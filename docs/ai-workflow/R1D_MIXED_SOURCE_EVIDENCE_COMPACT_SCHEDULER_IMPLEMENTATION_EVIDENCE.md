## Production change

`sourceEvidenceIdRepairAffectedRecordsAreClosed` admits only a nonempty complete
affected set where:

1. every failure is the existing malformed/unknown/wrong-page Source Evidence
   code;
2. page, coverage index and beat are safe, current and unique;
3. the draft has exactly one named page and one exact coverage beat at the
   recorded index;
4. current Source Evidence resolution recomputes the exact recorded failure;
5. each affected page has current same-page catalog choices; and
6. action-bound coverage has one exact same-beat action.

`assembleTemplateFromDraft` may expose that exact complete set to the existing
source patch selector. The existing atomic parser, prompt/schema authority and
applier are unchanged. A failed eligibility proof leaves all prior routing
unchanged.
