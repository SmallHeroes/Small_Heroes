## Calls and separate evaluation phases

Reuse GPT case1; generate Opus case1 plan/draft/edit and both arms of case2
plan/draft/edit: at most9 new model calls. No storyboard, images or narration.
This compares planner-plus-writer pipelines, not isolated prose ability.

Distribute first-draft pairs first, hiding model, cost, timing, allocation and
editor assertions. Seal judgments before giving edit pairs and final texts.
Judge edit gains separately as revision versus its own original. Historically
saved edits cannot be uncreated; they simply stay out of the first review phase.
New editor calls should wait until draft judgments are sealed where practical.

Use A/B/tie/neither and passages supporting curiosity, causal personal details,
child emotion/agency, companion desire/identity, situational humor, natural

an arbitrary location count. Code independently measures spread count and word
targets; those metrics never stand in for literary quality. No automatic9/10

usage stays visible and stops the bounded attempt.
